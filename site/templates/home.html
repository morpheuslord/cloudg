Three ways in

01 · full pipeline Collect, scan, report Every provider in parallel, all four scanners and every report format, in one command. cloudg run -p all --regions all 02 · ingest only Merge output you already have No cloud credentials and no scanner binaries. Point it at the files and get the same reports. cloudg ingest --prowler ./out/ 03 · map only Inventory, every service linked Typed edges such as INVOKES, ASSUMES_ROLE and PROTECTS, with no scanner involved. cloudg map -p aws --org

What happens in a run

Collectors read each provider concurrently and hand assets and edges to a NetworkX graph. Scanners run in parallel against the same accounts, their output is normalised into one finding model, deduplicated and matched to compliance controls. The same data then leaves as an HTML report, JSON, GraphML, an RDF ontology, RAG chunks and, if you want it, an MCP server for your AI assistant.
